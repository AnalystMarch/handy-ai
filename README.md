# Handy

### AI shortcuts at your fingertips on macOS

Handy brings AI assistance anywhere on your Mac with a lightweight menubar app and global shortcuts. Select text in any application and instantly improve, translate, summarize, or reply — without switching windows.

<br>

---

## Features

| | |
|:---|:---|
| **System-wide Shortcuts** | Trigger AI actions from any app with customizable hotkeys |
| **Smart Selections** | Works with any selected text in any macOS application |
| **Quick Actions** | Rewrite, explain, translate, fix grammar, or ask a custom question |
| **Menubar Presence** | Minimal footprint — stays out of the way until you need it |
